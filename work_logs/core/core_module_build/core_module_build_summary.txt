四、公开函数
------------
1. rough_align(x, y) -> (y_aligned, delay)
   通过完整线性互相关估计整数延迟，再对 y 执行循环移位。delay 是实际施加到 y 的整数位移。

2. fine_align(x, y, subtime=256, ns=None) -> (y_aligned, fraction_delay)
   按 Fine_Align.m 在 [-subtime, subtime-1] 网格搜索频域相关峰值并进行相位旋转。
   MATLAB 返回网格整数，本 Python 接口返回实际施加的采样位移 grid_delay/subtime。
   默认 subtime=256，与 experiment_2026_0816 采集脚本一致。

3. adjust_complex_gain(x, y) -> (y_adjusted, gain)
   gain=(y^H x)/(y^H y)，y_adjusted=gain*y。只做复增益匹配，不做峰值或功率归一化。

4. preprocess_pair(x, y, subtime=256, ns=None) -> y_processed
   固定执行 rough_align -> fine_align -> adjust_complex_gain。

5. nmse(x, y) -> nmse_db
   只计算 10*log10(sum(|x-y|^2)/sum(|x|^2))；完全相同时返回 -Inf。

6. cnmse(y_ref, y_test) -> cnmse_db
   只计算 10*log10(sum(|y_ref-y_test|^2)/sum(|y_ref|^2))；不调用对齐、校准或归一化。

7. acpr(signal, fs, bandwidth, spacing) -> (lower_db, upper_db)
   迁移 aclr.m/chan_pow.m/dbp.m：默认 Hann 窗、向下取不超过输入长度的最大 2 次幂 FFT、
   MATLAB 一基频带边界换算、主信道与正负 spacing 邻道功率积分。输出顺序为下邻道、上邻道。

五、输入约束
------------
- signal 对齐和校准要求等长、非空、一维、有限 complex ndarray。
- NMSE/CNMSE/ACPR 接受一维有限数值 ndarray。
- 函数不修改输入数组。
- 零参考能量、零主信道功率、非法频带或非法搜索参数会显式抛出 ValueError。

七、后续调用方式
----------------
任务入口脚本应将项目 scripts/ 加入 Python 搜索路径，再通过完整包名导入；不要把
scripts/_core/ 本身加入 sys.path，否则 _core/signal 可能遮蔽 Python 标准库 signal。

示例：

from pathlib import Path
import sys

scripts_root = Path(__file__).resolve().parents[1]
sys.path.insert(0, str(scripts_root))

from _core.signal import preprocess_pair
from _core.metrics import acpr, cnmse, nmse

y_processed = preprocess_pair(x, y, subtime=256)
nmse_db = nmse(x, y_processed)
lower_db, upper_db = acpr(y_processed, fs, bandwidth, spacing)

CNMSE 的两个输入必须由调用方预先按研究设计完成处理；cnmse() 内部不会自动对齐或调整复增益。
