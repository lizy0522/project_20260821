四、state_id定义
---------------
排序顺序固定为：

funMng -> funAng -> secMng -> secAng -> Vm -> Pin

状态空间不是四个幅相列表的直接笛卡尔积。零幅度时只允许零相位：

- 基波有效条件：(0,0°) + {10,20,30} × {0,45,...,315°} = 25
- 二次谐波有效条件：(0,0°) + {15,30} × {0,45,...,315°} = 17
- Vm固定为2.30，Pin固定为-21
- 总状态数：25 × 17 × 1 × 1 = 425
- state_id范围：0至424

代表状态：
- state_id=0   -> (0, 0, 0, 0, 2.30, -21)
- state_id=100 -> (10, 180, 30, 270, 2.30, -21)
- state_id=424 -> (30, 315, 30, 315, 2.30, -21)

build_state_table() 返回425行字典副本；get_state_info(state_id) 返回六参数字典；
get_state_id(funMng,funAng,secMng,secAng,Vm,Pin) 执行反向查询。无效零幅度/非零相位组合会报错。

五、文件索引
------------
实际文件名解析格式：

funMng_010_funAng_045_secMng_015_secAng_090_
vCarrier_2.30_inputPower_-21.00.mat

公开映射：
- STATE_FILE_MAP：state_id -> Path，共425项
- PARAM_FILE_MAP：(funMng,funAng,secMng,secAng,Vm,Pin) -> Path，共425项
- FILE_STATE_MAP：Path -> state_id，共425项

索引初始化时会检查：
- 文件名能否完整解析六参数；
- 参数是否属于425个有效状态；
- 是否存在重复 state_id 或重复参数；
- 是否缺失任一 state_id；
- 实际MAT数量是否严格等于425。

Windows深路径扫描和MAT加载统一使用 \\?\ 扩展长度路径，公开映射仍保存普通可读 Path。

六、数据访问方式
----------------
1. load_by_id(state_id)
   读取指定状态MAT中的全部业务变量。返回字典会移除 __header__、__version__、__globals__，
   不压缩原始数组维度。当前每个状态返回46个业务变量。

2. load_by_condition(funMng,funAng,secMng,secAng,Vm,Pin)
   先由六参数确定 state_id，再调用 load_by_id。

3. load_variable_by_id(state_id,variable_name)
   使用 scipy.io.loadmat(variable_names=[...]) 只读取指定变量；变量不存在时抛出 KeyError。

4. PAStateDataset
   len(dataset)=425；dataset[state_id]读取对应完整MAT；按state_id从0到424迭代。
   Dataset不缓存MAT内容，重复访问会重新只读加载文件。
